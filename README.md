# Mawkeb Saheb al-Zaman website

The website of Mawkeb Saheb al-Zaman, a Shia community in the Detroit area: the homepage with the scroll-driven latm footage and the trail of Abna Al-Batoul years, five program pages, four Get Involved pathways, the store, social media, about, contact and questions.

- **Run it:** `python -m http.server 8080`, then open http://localhost:8080/
- **Set it up and hand it over:** see [SETUP.md](SETUP.md) for the settings file, forms, donations, the store, editing content and publishing.
- **House style:** Ink `#121309`, white and Mawkeb green `#427D46` (deep `#336137`, wash `#ECF2EC`); Montserrat, with Dubai for Arabic.
